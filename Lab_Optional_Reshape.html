Wide vs. Long Data

Data can be stored in two formats: wide and long.

  • Wide format: Each row is a unit (e.g., a state) and different time periods are stored in separate columns.
  • Long format: Each row is a unit-time observation (e.g., a state in a given year).

Many statistical operations in STATA require data in long format. The reshape command converts between the two.

Q1: This data is in “wide” format. Use reshape long to convert it to “long” format so that each row is a state-year observation. How many observations do you have after reshaping? What does the variable year represent?

Hint: The syntax is reshape long hourwage black, i(state_fips) j(year). The i() option specifies the unit identifier and j() specifies the time variable that STATA will create.

reshape long hourwage black, i(state_fips) j(year)
des
browse

After reshaping, you should have 204 observations (51 states x 4 years).
